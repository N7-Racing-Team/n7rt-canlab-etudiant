# CAN Lab 0.3 — démarrage en 5 minutes

1. **Installer.** Décompressez `n7rt-canlab-0.3.0-windows-x64.zip` dans un dossier où vous pouvez écrire, lancez `n7rt-can-lab.exe` (SmartScreen : « Informations complémentaires », puis « Exécuter quand même »). Pour compiler et programmer : Python 3.11+, GNU ARM, STM32CubeProgrammer, puis `python -m pip install -r .\requirements-student-ide.txt`.
2. **Brancher.** NUCLEO-H753ZI sur son port ST-LINK ; dans la barre du haut, choisissez le port dans **CARTE**, puis **Connecter**. Attendez « Prête ».
3. **Ouvrir la mission.** Dans le **Cockpit** (deuxième bouton de la barre d'activité, à gauche ; au premier lancement l'application s'ouvre sur **Code STM32**), choisissez la mission de votre groupe (définitif), **Importer le pack du groupe…** (`.n7rtpack`), saisissez le code du groupe dans **Code du groupe**, **Ouvrir**. Lisez l'énoncé du panneau de la mission, dont les « Sorties à publier » (le slot de chaque sortie).
4. **E0, essai nominal.** Repérez les trames de votre ECU dans le Cockpit (**Start**), écrivez votre décodeur dans **Code STM32**, compilez, arrêtez la session (**Stop**), programmez. Ne modifiez pas les « Paramètres » des composants du banc : chaque vérification compare votre banc au banc de référence. Remplissez la fiche (**Ouvrir la fiche** : elle s'ouvre en bas du Cockpit, onglet **Fiche**), **Enregistrer la fiche**, puis **Lancer la vérification**.
5. **E1 à E3, incidents.** Le véhicule revient avec une anomalie : observez (bus, slots, Physical Lab) ; dans la fiche d'incident, choisissez la cible, la catégorie et l'état observé, qui impose la grandeur à relever ; relevez-la au multimètre ou sur le bus, session démarrée (**Start**), puis **Consigner la mesure** (dans la fiche, ou sous le multimètre) là où l'anomalie se voit ; saisissez valeur et unité, **Enregistrer la fiche** ; réparez (circuit, code ou les deux), **Vérifier la réparation**. Réparé trop tôt ? **Reproduire l'anomalie**.
6. **E4, qualification.** **Lancer la qualification**, carte branchée : huit lignes CP, toutes en PASS pour clôturer.
7. **E5, clôture.** **Ouvrir la fiche finale** : le dossier est dans `Documents/N7RT CAN Lab/fiches/`.

Entre deux vérifications : 2 minutes (E0 à E3), 5 minutes (E4). Vous pouvez fermer l'application entre deux essais : ce qui est enregistré est repris à la réouverture, et une fiche aux modifications non enregistrées vous propose **Enregistrer et fermer** avant de se fermer. Le détail de chaque écran est dans le [tutoriel complet](N7RT_CANLab_0.3_Tutoriel_Etudiant.pdf).
